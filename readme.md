# Scientific Machine Learning (SciML)

This is the main repository for my work on **Scientific Machine Learning**. It organizes research articles by topic, with each paper having its own dedicated repository containing the accompanying reproducible files. The articles link to preprints, which may differ from the final published versions.

The long-term goal is to build a comprehensive and reusable library of methods, algorithms, and resources for Scientific Machine Learning.
